# overfitlab

Statistics that separate a real trading signal from a lucky one. The library implements purged and combinatorial purged cross-validation, the Probabilistic and Deflated Sharpe Ratios, the Probability of Backtest Overfitting, White's Reality Check, Hansen's SPA, the Romano–Wolf stepdown, minimum backtest length and the Harvey–Liu Sharpe haircut.

This site is under construction. See the [decisions log](decisions.md) for what has been settled so far.
